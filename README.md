# AI异常调查局：失控的分类器

面向大学 AI 社团零基础大一新生的机器学习入门网页游戏。

玩家调查“流浪动物识别机器人把橘猫认成面包”的事故，亲手经历：观察数据 → 选择特征 → 训练真实分类器 → 未知数据审计 → 查看误判 → 遇到过拟合 → 修复系统。

第一版是一个无后端、无需注册、无需 Python、浏览器本地运行的完整单人垂直切片。

## 已实现

- 4 个语义特征：颜色暖度、轮廓圆度、表面纹理、长宽比例。
- 真实本地模型：线性分类器、深度 2 决策树、KNN k=1 / k=5。
- SVG 散点图、实时决策边界、训练/测试指标与可点击误判样本。
- “第一次成功 → 隐藏测试失败 → k=1 过拟合陷阱 → 修复”的完整第一关。
- AI 助理“小析”三级提示。
- 迁移问题与通关总结。
- 固定随机种子与匿名行为日志。
- `?debug=1` 开发者测试模式：跳关、重置、真值、模型参数、预测、边界原始数据、动画速度、六类自动路线、日志导出。
- Vitest 核心/状态机/自动路线测试。
- GitHub Actions CI。

## 本地运行

正式工具链使用 Node.js 24 LTS。

```bash
npm install
npm run dev
```

默认打开 Vite 提示的本地地址即可。

开发者测试模式：

```text
http://localhost:5173/?debug=1
```

指定固定种子：

```text
http://localhost:5173/?debug=1&seed=20260809
```

## 验证

```bash
npm run check
npm test -- --run
npm run build
```

当前固定种子 `20260809` 的关键教学结果：

- 初始捷径：暖度 + 圆度 + 直线 → 训练 88.9%，未知测试 66.7%。
- 过拟合陷阱：纹理 + 长宽比 + k=1 → 训练 100%，未知测试 79.2%。
- 稳健修复：纹理 + 长宽比 + 直线 / 浅树 / k=5 → 未知测试 100%。

结果均由浏览器模型真实计算，不在 UI 中写死。
